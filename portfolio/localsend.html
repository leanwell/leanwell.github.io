LocalSend

Filipino Translator Open Source Contribution

About The Project

LocalSend is a free, open-source application that allows users to securely share files and messages with nearby devices over a local network without needing an internet connection. It serves as a privacy-first, cross-platform alternative to proprietary ecosystems like AirDrop.

My Contribution

As an active contributor to the open-source community, I led the comprehensive Filipino (Tagalog) localization for the entire LocalSend ecosystem. Ensuring technology is accessible to native speakers in the Philippines is crucial for global adoption.

My translation work spans across multiple facets of the project:

  • Mobile & Desktop Application: Translated the core UI/UX strings for iOS, Android, Windows, macOS, and Linux clients, ensuring the terminology feels natural and intuitive to Filipino users.
  • Official Website: Localized the main localsend.org website, allowing Filipino users to understand the app's privacy features and documentation in their mother tongue.
  • GitHub Repository: Contributed directly via Pull Requests, helping maintain the translation matrices and documentation guidelines.
