How to Install on Android

Installing signed APKs directly gives you immediate access to releases without app store delays.

1

Download APK

Click the download button to grab Downloader-arm64-v8a.apk (~60.5 MB) directly onto your phone.

2

Open the File

Tap the download notification. If prompted, allow "Install unknown apps" for your browser in system settings.

3

Complete Installation

Tap Install on the Android package installer prompt. Once complete, launch Downloader and start grabbing media.
